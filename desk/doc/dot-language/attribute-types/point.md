# point

2-dimensional (or 3-dimensional) geometrical point in space

`"%f,%f('!')?"` representing the point `(x,y)`. The optional `'!'` indicates the node position should not change (input-only).

If `[dim](../attributes/dim.md)=3`, `point` may also have the format `"%f,%f,%f('!')?"` to represent the point `(x,y,z)`.

## Attributes

`point` is a valid type for:

  * [head_lp](../attributes/head_lp.md)
  * [lp](../attributes/lp.md)
  * [margin](../attributes/margin.md)
  * [pad](../attributes/pad.md)
  * [page](../attributes/page.md)
  * [pos](../attributes/pos.md)
  * [scale](../attributes/scale.md)
  * [size](../attributes/size.md)
  * [tail_lp](../attributes/tail_lp.md)
  * [xlp](../attributes/xlp.md)
