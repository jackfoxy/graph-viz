# lblString

Label string

An [escString](esc-string.md) or an [HTML label](../node-shapes.md#html-like-labels).

## Attributes

`lblString` is a valid type for:

  * [headlabel](../attributes/headlabel.md)
  * [label](../attributes/label.md)
  * [taillabel](../attributes/taillabel.md)
  * [xlabel](../attributes/xlabel.md)
