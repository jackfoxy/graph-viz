# shape

the [shape](/doc/info/shapes.html) of a node

There are three main types of shapes:

  * [polygon-based](/doc/info/shapes.html#polygon),
  * [record-based](/doc/info/shapes.html#record) and
  * [user-defined](/doc/info/shapes.html#epsf).



The record-based shape has largely been superseded and greatly generalized by [HTML-like labels](/doc/info/shapes.html#html). That is, instead of using `shape=record`, consider using `shape=none` and an HTML-like label.

## Attributes

`shape` is a valid type for:
