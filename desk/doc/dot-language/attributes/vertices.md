# vertices

Sets the coordinates of the vertices of the node's polygon, in inches

type: [pointList](../attribute-types/pointList.md)

Used if the node is polygonal, and output is `dot` or `xdot`.

If the node is an ellipse or circle, the [samplepoints](samplepoints.md) attribute affects the output.

_Valid on:_

  * Nodes



**Note:**  write only.
