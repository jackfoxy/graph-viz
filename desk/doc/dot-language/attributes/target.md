# target

If the object has a [URL](url.md), this attribute determines which window of the browser is used for the URL.

type: [escString](../attribute-types/escString.md) | [string](../attribute-types/string.md), default: `<none>`

See [W3C documentation](http://www.w3.org/TR/html401/present/frames.html#adef-target).

_Valid on:_

  * Edges
  * Nodes
  * Graphs
  * Clusters



**Note:**  map,[svg](/docs/outputs/svg/) only.
