# arrowhead

Style of arrowhead on the head node of an edge

type: [arrowType](../attribute-types/arrowType.md), default: `normal`

This will only appear if the [dir` attribute](dir.md) is `forward` or `both`.

See the [limitation](../attributes.md#undir_note).

See also:

  * [arrowtail](arrowtail.md)

_Valid on:_

  * Edges
