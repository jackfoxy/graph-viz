# samplepoints

Gives the number of points used for a circle/ellipse node

type: [int](../attribute-types/int.md), default: `8` (output) , `20` (overlap and image maps)

Used if the input graph defines the [vertices](vertices.md) attribute, and output is `dot` or `xdot`.

It plays the same role in `neato`, when adjusting the layout to avoid overlapping nodes, and in image maps.

_Valid on:_

  * Nodes
