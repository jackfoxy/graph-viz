# labeldistance

Scaling factor for the distance of [headlabel](headlabel.md) / [taillabel](taillabel.md) from the head / tail nodes.

type: [double](../attribute-types/double.md), default: `1.0`, minimum: `0.0`

The default distance is 10 points.

`labeldistance` multiplies that default.

See [labelangle](labelangle.md) for more details.

_Valid on:_

  * Edges
