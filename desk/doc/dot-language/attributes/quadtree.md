# quadtree

Quadtree scheme to use

type: [quadType](../attribute-types/quadType.md) | [bool](../attribute-types/bool.md), default: `normal`

  * `quadtree=true` aliases `quadtree=normal`
  * `quadtree=false` aliases `quadtree=none`
  * `quadtree=2` aliases `quadtree=fast`

_Valid on:_

  * Graphs



**Note:** [sfdp](/docs/layouts/sfdp/) only.
