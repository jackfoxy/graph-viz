# labelfontsize

Font size of `headlabel` and `taillabel`

type: [double](../attribute-types/double.md), default: `14.0`, minimum: `1.0`

Font size, [in points](../attributes.md#points), used for [headlabel](headlabel.md) and [taillabel](taillabel.md).

If not set, defaults to edge's [fontsize](fontsize.md).

_Valid on:_

  * Edges
