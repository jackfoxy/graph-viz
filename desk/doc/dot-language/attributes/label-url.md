# labelURL

If defined, `labelURL` is the link used for the label of an edge

type: [escString](../attribute-types/escString.md), default: `""`

`labelURL` overrides any [URL](url.md) defined for the edge.

See also:

  * [edgehref](edgehref.md), [edgeURL](edge-url.md)
  * [headhref](headhref.md), [headURL](head-url.md)
  * [labelhref](labelhref.md), [labelURL](label-url.md)
  * [tailhref](tailhref.md), [tailURL](tail-url.md)
  * [href](href.md), [URL](url.md)

_Valid on:_

  * Edges



**Note:**  map,[svg](/docs/outputs/svg/) only.
