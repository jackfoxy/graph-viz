# sortv

Sort order of graph components for ordering [packmode](packmode.md) packing.

type: [int](../attribute-types/int.md), default: `0`, minimum: `0`

If [packmode](packmode.md) indicates an array packing, `sortv` specifies an insertion order among the components, with smaller values inserted first.

_Valid on:_

  * Graphs
  * Clusters
  * Nodes
