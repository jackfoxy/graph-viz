# scale

Scales layout by the given factor after the initial layout

type: [double](../attribute-types/double.md) | [point](../attribute-types/point.md)

If only a single number is given, that number scales both width and height.

_Valid on:_

  * Graphs



**Note:** [neato](/docs/layouts/neato/), [twopi](/docs/layouts/twopi/) only.
