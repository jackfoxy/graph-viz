# arrowtail

Style of arrowhead on the tail node of an edge

type: [arrowType](../attribute-types/arrowType.md), default: `normal`

This will only appear if the [dir` attribute](dir.md) is `back` or `both`.

See the [limitation](../attributes.md#undir_note).

See also:

  * [arrowhead](arrowhead.md)

_Valid on:_

  * Edges
